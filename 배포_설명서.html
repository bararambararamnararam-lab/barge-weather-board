깃허브에 올리고, 폰·PC로 접속하는 법

아래 순서를 위에서부터 그대로 따라가면 된다. 한 단계가 끝나면 오른쪽 완료 체크를 누르면 되고, 어디까지 했는지는 이 페이지가 기억해 둔다 (브라우저를 닫았다 열어도 유지됨).

완료 0 / 7 예상 소요 시간 약 30분 저장소 위치 F:\AI\Weather_gathering\claude-weather

준비물

  • 깃허브(GitHub) 계정 — 없어도 된다, 1단계에서 같이 만든다.
  • 기상청 API 키 — claude-weather\.env 파일을 메모장으로 열면 KMA_HUB_API_KEY=… 줄에 있다. = 뒤의 글자만 쓴다.
  • 인터넷 되는 컴퓨터 — 지금 이 화면을 보고 있는 컴퓨터면 된다.

이 키는 이 설명서 어디에도 다시 적지 않는다. 4단계에서 딱 한 번, 깃허브의 비공개 금고(Secrets)에만 붙여넣는다. 그 값을 코드나 채팅창, 메모 파일에는 절대 남기지 않는다.

순서 7단계

  1. 1

    깃허브 계정 만들기

    계정 있으면 건너뛰기

    github.com 접속 → 오른쪽 위 Sign up → 이메일·비밀번호·아이디 입력 → 이메일로 온 인증 코드 입력. 이 계정이 앞으로 우리 프로그램을 보관하고 자동으로 돌리는 창고 계정이 된다.

  2. 2

    저장소(창고) 만들기

    로그인 후 오른쪽 위 + 버튼 → New repository.

    1. Repository name: 아무 이름이나 괜찮다. 예 weather-board
    2. Public 선택 — 아래 콜아웃 참고.
    3. 다른 옵션은 그대로 두고 Create repository 클릭.

    왜 Public 인가 — 깃허브 무료 플랜은 비공개 저장소에서 Pages(웹 화면 켜기) 기능 자체를 못 쓴다. Private 로 만들면 5단계에서 막힌다. Public 으로 하면 소스 코드·설정 파일·항로 좌표(영성·CSME 경유지)까지 인터넷에서 누구나 볼 수 있게 된다. 기상 데이터 자체는 원래 출처를 밝히고 쓰는 공개 자료라 상관없고, 보는 사람도 사내 몇 명뿐이라 이 프로젝트는 이 정도 노출을 감수하기로 했다. API 키(.env)와 데이터베이스는 애초에 저장소에 올라가지 않으니 이걸로 새로 새는 건 없다. 항로 좌표까지 가리고 싶으면 월 $4 짜리 GitHub Pro 또는 무료인 Cloudflare Pages 로 대신 갈 수 있다 (README 9절).

    초록 버튼과 명령어가 잔뜩 적힌 안내 화면이 뜨는데, 그대로 두고 다음 단계로 넘어간다. 거기 적힌 명령어는 안 써도 된다 — 이미 우리 프로젝트에 파일이 다 있기 때문이다.

  3. 3

    내 컴퓨터 파일을 저장소로 올리기

    시작 메뉴에서 cmd 검색 → 명령 프롬프트 실행. 아래 세 줄을 한 줄씩 붙여넣고 Enter. <내 계정 이름>과 <저장소 이름>은 2단계에서 정한 실제 값으로 바꿔 넣는다.

    명령 프롬프트 
    cd F:\AI\Weather_gathering\claude-weather
git remote add origin https://github.com/<내 계정 이름>/<저장소 이름>.git
git push -u origin main

    마지막 줄에서 브라우저 로그인 창이 뜨면 깃허브 계정으로 로그인해서 허가해 준다. 창이 안 뜨고 멈춰 있으면 작업 표시줄에 새로 뜬 브라우저 창을 확인해라.

    확인 방법: 저장소 페이지를 새로고침해서 README.md, src, web 폴더가 보이면 성공이다.

  4. 4

    기상청 키를 금고에 넣기

    저장소 화면에서 Settings 탭 → 왼쪽 메뉴 Secrets and variables → Actions → New repository secret.

    1. Name 칸에 정확히 KMA_HUB_API_KEY (대소문자·밑줄까지 그대로)
    2. Secret 칸에 .env 파일에서 복사한 키 값 붙여넣기 (앞뒤 공백 없이)
    3. Add secret 클릭

    여기 넣은 값은 깃허브 화면에서도 다시 볼 수 없다. 자동 실행 로그에도 *** 로 가려져 나온다. 틀렸으면 같은 이름으로 새로 만들어 덮어쓰면 된다.

  5. 5

    자동 실행 방식 켜기

    Settings → Pages 로 들어갔는데 "Upgrade or make this repository public to enable Pages" 라는 문구가 뜬다면, 2단계에서 저장소를 Private 로 만든 경우다. 그러면 먼저 이것부터 한다:

    1. 같은 Settings 화면(General)을 맨 아래까지 내린다
    2. 빨간 테두리 Danger Zone 구역의 Change visibility 클릭
    3. Change to public 선택 → 저장소 이름을 다시 입력해 확인

    그다음 Settings → 왼쪽 메뉴 Pages → Build and deployment 항목의 Source 드롭다운을 GitHub Actions 로 바꾼다.

    기본값인 "Deploy from a branch" 로 남겨 두면 화면이 영영 안 뜬다. 꼭 "GitHub Actions" 로 바꿔야 한다.

  6. 6

    처음 한 번 손으로 실행해 보기

    Actions 탭 → 왼쪽 목록의 기상자료 수집 클릭 → 오른쪽 Run workflow 버튼 → 다시 뜨는 초록 Run workflow 버튼 클릭.

    5~8분 걸린다. 목록의 동그라미가 노란색(진행 중) → 초록 체크(성공)로 바뀌면 끝이다. 빨간 X 가 뜨면 아래 8절 문제 해결을 봐라.

    처음 실행이라 데이터베이스가 비어 있는 상태에서 시작한다. 5~8분짜리 실행이 끝나면 15개 지점의 10일치 예보가 다 채워진다.

  7. 7

    접속 주소 확인하고 폰에 추가하기

    주소 형식은 다음과 같다. Settings → Pages 화면 위쪽에도 실제 주소가 나온다.

    접속 주소 
    https://<내 계정 이름>.github.io/<저장소 이름>/
    1. PC — 주소창에 입력 후 Ctrl+D 로 즐겨찾기
    2. 아이폰(사파리) — 공유 아이콘 탭 → 홈 화면에 추가
    3. 안드로이드(크롬) — 오른쪽 위 점 3개 → 홈 화면에 추가 / 앱 설치

    홈 화면에 추가하면 브라우저 주소창 없이 앱처럼 아이콘만 눌러서 바로 열린다 (화면에 이미 전용 아이콘이 설정돼 있다).

    선택 — 주소가 길어서 외우기 힘들면 짧은 링크로 바꾸기
    깃허브 주소는 그대로 두고, 짧은 링크 하나만 따로 만드는 방법이다. 무료고 가입도 필요 없다.

    1. tinyurl.com 접속
    2. 위 접속 주소를 그대로 붙여넣기
    3. Alias(선택) 칸에 원하는 이름을 직접 넣을 수 있다. 예: tinyurl.com/우리회사기상
    4. Create my TinyURL 클릭 → 짧은 링크 완성

    만들 때 같이 뜨는 QR코드를 캡처해서 사내 게시판·메신저에 붙여 두면, 폰 카메라로 찍기만 해도 바로 들어올 수 있다.

8 문제가 생겼을 때

증상확인 / 해결
Actions 탭에 빨간 X그 실행을 클릭 → 아래로 펼쳐지는 로그 확인. 거의 대부분 KMA_HUB_API_KEY 오타나 앞뒤 공백이 원인이다 → 4단계를 다시 확인
주소 접속 시 화면이 안 뜸(404)Settings → Pages → Source가 GitHub Actions 인지 재확인. 아직 한 번도 성공 실행이 없으면 6단계부터 다시
git push 시 "Authentication failed"브라우저 로그인 창이 새로 떴는지 작업 표시줄 확인. 안 뜨면 github.com 에 먼저 로그인해 둔 뒤 다시 실행
git push 시 "remote origin already exists" git remote remove origin 실행한 뒤 3단계 다시
매번 손으로 눌러야 갱신되는 것 같음정상은 자동이다. 위 시간표 시각을 하루 지나서 Actions 탭에 초록 체크가 새로 쌓이는지 확인해라

지금 data\weather.db 에 이미 모아 둔 자료(약 335 KB)는 이 절차로는 안 딸려 올라간다. 첫 실행은 빈 상태에서 시작한다. 그 파일을 이어서 쓰고 싶으면 따로 알려주면 옮기는 법을 알려주겠다.
